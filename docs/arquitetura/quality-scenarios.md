# Quality Scenarios (Cenários de Atributos de Qualidade)

Formato SEI/ATAM: **Fonte → Estímulo → Artefato → Ambiente → Resposta → Medida da resposta**. Cada cenário aponta a tática usada e onde verificar.

| ID | Atributo | Fonte | Estímulo | Artefato | Ambiente | Resposta | Medida | Tática / Evidência |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| QS-01 | **Desempenho** | Cliente | Abre o catálogo (`GET /products/catalog`) | API + Redis | Operação normal, cache aquecido | Responde a partir do cache | p95 < **150 ms**; taxa de acerto do cache ≥ **70%** | Cache-aside ([ADR 0003](adr/0003-cache-redis-cache-aside.md)); `GET /metrics` → `latencyMs.p95`, `sli.cacheHitRatio` |
| QS-02 | **Desempenho** | 50 clientes simultâneos | Navegam no catálogo e nos detalhes | API | Pico (campanha/lançamento) | Atende sem erros | p95 < **500 ms**, 0% de 5xx | Cache + índices no MySQL; teste de carga em [SLOs](slo-sli-resiliencia-observabilidade.md#teste-de-carga) |
| QS-03 | **Disponibilidade** | Falha de infraestrutura | Container do Redis cai | API | Operação normal | Continua respondendo direto do MySQL; reconecta sozinha quando o Redis volta | **0** requisições com erro; reconexão automática em < 5 s | Timeout de 500 ms, sem fila offline, *circuit breaker*, retry com backoff ([ADR 0003](adr/0003-cache-redis-cache-aside.md)). Verificado com `docker stop agnus-redis` |
| QS-04 | **Disponibilidade** | Falha de processo | Backend encerra inesperadamente | Container `backend` | Produção | Docker reinicia o container; Nginx volta a encaminhar | Recuperação < **30 s** | `restart: unless-stopped` + healthcheck `/health` |
| QS-05 | **Disponibilidade** | Falha de serviço | Meilisearch indisponível | Busca do catálogo | Operação normal | Busca cai para SQL local | **0** erros visíveis ao cliente | Fallback em `produtoSearchIndex.service.ts` ([ADR 0005](adr/0005-busca-meilisearch.md)) |
| QS-06 | **Consistência** | Administrador | Edita nome/preço de um produto | API + Redis | Cache aquecido | A próxima leitura já mostra o dado novo | Defasagem = **0 s** para produto/categoria/foto; ≤ **60 s** para mais vendidos | Invalidação síncrona por namespace + TTL curto |
| QS-07 | **Segurança** | Usuário com cargo `cliente` | Chama `DELETE /products/1` | API | Operação normal | Bloqueia | **403** em 100% dos casos; nada é alterado | RBAC (`permission.middleware.ts`) |
| QS-07b | **Segurança** | Usuário anônimo ou outro cliente | Lê ou altera endereço, carrinho, avaliação ou item de pedido de terceiros | API | Operação normal | Bloqueia | **401** sem token, **403** para recurso de outro usuário | `ownership.middleware.ts` + testes em `tests/middlewares/ownership.middleware.spec.ts` |
| QS-07c | **Segurança** | Usuário | Envia HTML ou executável renomeado para `.png` | Upload | Operação normal | Recusa | **400**; nada é gravado | Validação por magic bytes (`imageSignature.ts`) |
| QS-08 | **Segurança** | Atacante na rede | Tenta acessar MySQL/Redis diretamente | Infra Docker | Produção | Não há rota até os serviços de dados | Portas 3306/6379/7700 **não publicadas** | Rede `data` com `internal: true` ([ADR 0006](adr/0006-nginx-proxy-reverso.md)) |
| QS-09 | **Observabilidade** | Suporte | Cliente relata erro em uma compra | Logs | Produção | Encontra todos os logs do fluxo pelo id | Diagnóstico em < **10 min** | `X-Request-Id` + logs JSON ([ADR 0007](adr/0007-logs-estruturados.md)) |
| QS-10 | **Desacoplamento** | Pedido criado | Worker de notificações está fora do ar | API | Operação normal | Pedido é criado normalmente; só a notificação é perdida | **0** pedidos com falha por causa de eventos | Publicação *best effort* ([ADR 0004](adr/0004-eventos-redis-pubsub.md)) |
| QS-11 | **Modificabilidade** | Equipe | Adicionar um novo consumidor de eventos (ex.: e-mail) | Worker | Desenvolvimento | Novo handler sem tocar em quem publica | < **1 dia**, 1 arquivo alterado | Mapa `handlers` em `src/worker.ts` |
| QS-12 | **Testabilidade** | Desenvolvedor | Abre um PR | CI | GitHub Actions | Lint + testes + build rodam automaticamente | Feedback em < **5 min**; PR bloqueado se falhar | [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml) |
